# Design reference (mockups)

Nine HTML/SVG/CSS mockups of The Foundry: Main (hub), List, Quiver, Train, Vitals, Rank, Island (iPhone), Mac (dashboard), MenuBar (Mac popover).

- Read them for exact geometry, colors, spacing and copy.
- Ignore the `<x-dc>` / `<helmet>` wrappers and `support.js`.
- `{{accent}}` means `#62c47f`.
- Phone frames are 390x844 for proportion only. The real app must adapt to any screen.
- Do not modify these files.
